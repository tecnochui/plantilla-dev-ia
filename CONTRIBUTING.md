# Contribuir a Dev Template

## Convenciones de commits

Usa **Conventional Commits**:

```
<tipo>(<alcance>): <descripción>
```

Tipos válidos: `feat`, `fix`, `security`, `docs`, `chore`, `refactor`, `test`, `perf`.

Ejemplo: `feat(prompts): añadir prompt para auditoría de dependencias`

## Flujo de trabajo

1. Forkea el repositorio.
2. Crea una rama: `git checkout -b feat/mi-mejora`.
3. Haz tus cambios.
4. Asegúrate de que pasan los hooks (`pre-commit` y `commit-msg`).
5. Push a tu rama: `git push origin feat/mi-mejora`.
6. Abre un Pull Request.

## Código de conducta

Sé respetuoso. No se tolera acoso ni discriminación.
